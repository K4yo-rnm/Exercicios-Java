Repositório dedicado aos meus estudos e exercícios práticos em **Java**, desenvolvidos durante minha formação em Ciência da Computação.

## O que foi estudado e aplicado

### 1. Programação Orientada a Objetos (POO)

- Criação de classes e objetos.
- Atributos, métodos e construtores.
- Construtores parametrizados.
- Encapsulamento e modificadores de acesso.
- Herança e reutilização de código.
- Polimorfismo e sobrescrita de métodos.
- Classes abstratas.

### 2. Expressões Lambda e Java Streams

- Criação e utilização de expressões Lambda.
- Interfaces funcionais.
- Interface Predicate.
- Processamento e manipulação de coleções.
- Operações com Stream API.
- Filtragem de elementos com `filter()`.
- Transformação de dados com `map()`.
- Ordenação com `sorted()`.
- Remoção de duplicatas com `distinct()`.
- Operações de agregação com `sum()`, `max()` e `min()`.
- Manipulação de valores com `Optional`.

### 3. Programação Concorrente

- Fundamentos de Threads.
- Criação de threads utilizando a classe `Thread`.
- Execução concorrente de tarefas.
- Inicialização com `start()`.
- Sincronização da finalização com `join()`.

### 4. Tratamento de Exceções

- Utilização de `try`, `catch` e `throw`.
- Tratamento de situações excepcionais.
- Criação de exceções personalizadas.
- Validação de dados e entradas.

### 5. Manipulação de Arquivos

- Conceitos de leitura e manipulação de arquivos.
- Listagem e localização de arquivos.
- Utilização de recursos da API de arquivos do Java.

### 6. Interface Gráfica com Java Swing

- Criação de interfaces gráficas.
- Utilização de componentes como botões e painéis.
- Organização de componentes com layouts.
- Tratamento de eventos e interações do usuário.

## Tecnologias e Ferramentas

- **Java:** linguagem utilizada no desenvolvimento dos exercícios.
- **Java Collections Framework:** manipulação de estruturas de dados.
- **Java Streams API:** processamento de coleções.
- **Java Swing:** desenvolvimento de interfaces gráficas.
- **Git e GitHub:** versionamento e organização dos códigos.
- **IDE:** ambiente de desenvolvimento para escrita e execução dos exercícios.

## Objetivo do Repositório

Este repositório representa parte da minha jornada de aprendizado em Java e desenvolvimento de software.

Cada exercício contribui para o fortalecimento da lógica de programação, compreensão dos fundamentos da linguagem e aplicação de boas práticas de desenvolvimento.

O conteúdo será atualizado conforme avanço nos estudos e desenvolvo novos projetos.
